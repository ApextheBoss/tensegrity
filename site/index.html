The Problem

Your agents have no safety net

Multi-agent systems fail in ways LLM wrappers can't fix.

💥

Cascading Failures

One agent goes down. Three dependents retry. Retries overload the system. Everything dies in 8 seconds. You needed a circuit breaker.

🌊

Uncontrolled Load

Fast producer, slow consumer. Queue fills to 100K messages. Memory spikes. OOM kill. You needed backpressure.

🔒

Shared State Chaos

Two agents update the same resource. Race condition. Data corruption. You needed distributed locks or CRDTs.

🎯

Blind Routing

Task goes to a random agent. That agent is overloaded. Another is idle. You needed reputation-aware routing.

👻

Silent Degradation

Agent latency creeps from 200ms to 5s. Nobody notices until users complain. You needed health monitoring.

🏗️

DIY Infrastructure

Every team building multi-agent systems reinvents the same primitives. Badly. In application code. You needed a library.

Code

Real code, not pseudo-code

// Protect agent calls with a circuit breaker
import { CircuitBreaker } from 'tensegrity';

const breaker = new CircuitBreaker('agent-search', {
  failureThreshold: 3,
  resetTimeoutMs: 30_000,
  monitorWindowMs: 60_000,
});

const result = await breaker.execute(() =>
  searchAgent.query('latest earnings report')
);
// After 3 failures in 60s → fast-fails for 30s
// Then allows one probe request to test recovery

Circuit Breakers

Stop cascading failures before they start. When a downstream agent starts failing, the breaker opens and fast-fails requests instead of piling on.

  • Sliding window failure tracking
  • Half-open state with probe requests
  • Per-agent or per-service granularity
  • Event callbacks for monitoring
// Route tasks to the best available agent
import { ReputationRouter } from 'tensegrity';

const router = new ReputationRouter();

router.register('agent-1', ['summarize', 'translate']);
router.register('agent-2', ['summarize', 'classify']);

// Route based on reputation + capability match
const agent = router.route('summarize');

// Report outcomes to update reputation
router.reportSuccess(agent, 150); // 150ms
router.reportFailure(agent);

Reputation-Aware Routing

Don't send tasks to random agents. Route based on track record — success rates, latency, and capability match.

  • EWMA-smoothed reputation scores
  • Capability-based matching
  • Automatic load shedding from poor performers
  • Decay function for stale reputation data
// Coordinate with gossip-based discovery
import { GossipProtocolEngine } from 'tensegrity';

const gossip = new GossipProtocolEngine({
  nodeId: 'node-1',
  fanout: 3,
  gossipIntervalMs: 1000,
});

// Spread state across the cluster
gossip.setLocal('status', 'healthy');
gossip.setLocal('load', 0.42);

// Eventually consistent — all nodes converge
const peerLoad = gossip.getRemote('node-2', 'load');

Gossip Protocol

Decentralized service discovery and state dissemination. No central registry. No single point of failure.

  • SWIM-style failure detection
  • Crescent protocol for efficient dissemination
  • Automatic membership management
  • Configurable fanout and intervals
